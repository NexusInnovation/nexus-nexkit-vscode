## Defects found beyond the audit list

Two, both real and both previously undetected:

1. **`Check-Validation.ps1` resolved the settings path one directory _above_ the project root** — so `check → validate → check` never converged **on Windows either**. The divergence was three-way, not two-way as originally believed.
2. **The bash version normalizer (`sed 's/[^0-9.].*//'`) returned an empty string** for `v22.1.0` and `git version 2.43.0` — meaning **Node and Git were reported OUTDATED on every Unix run.** Replaced with a first-match `grep -oE '[0-9]+(\.[0-9]+)*'` contract, verified 8/8 identical PASS/FAIL against the PowerShell implementation.

**One audit item correctly rejected as a false positive:** `local_exit_code` in `validate-prerequisites.sh` is a _variable name_, not a misplaced `local` keyword. Valid bash. Deliberately left alone — "fixing" it would break the script.
