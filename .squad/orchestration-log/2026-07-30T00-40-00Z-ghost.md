## Files produced / modified

1. **Descendant process leak on cancel (should-fix #2).** `NodeProcessRunner` now spawns `detached: true` on POSIX and kills the negative PID so the whole group dies; Windows escalates through `taskkill /PID <pid> /T /F`. Where the tree kill cannot be delivered, the new `ScriptRunResult.descendantsMaySurvive` flag surfaces it and the cancellation message warns an installer may still be running — the limitation is surfaced, never silently swallowed.

2. **`"cancelled"` promoted to a first-class `ScriptRunOutcome` (should-fix #3).** The `failureReason: "cancelled"` magic string is gone. `_resolvePowerShellCommand` and `_ensureJq` now check the token _after_ their probes fail and immediately before throwing, so an interrupted run no longer falsely reports a missing PowerShell host or missing `jq`. The check is deliberately late, not eager, to preserve `furthestStep === "check"` for a pre-cancelled run.

3. **UTF-8 decoded at the stream, not per chunk (should-fix #4).** Both child streams use `setEncoding("utf8")`, so multi-byte characters split across chunk boundaries no longer corrupt the log — which matters because the reference scripts emit accented French and `✓`/`⚠`.

4. **Phantom `NEXKIT_NON_INTERACTIVE` removed (Trinity D1).** The extension set it; no script ever read it. Windows non-interactivity is genuinely enforced by `-Interactive:$false`, which stays. The test now asserts the flag is _absent_.

5. **Marker parsing aligned to the contract (Trinity D2).** `parseValidationMarker` is now case-sensitive, allows no separator, and takes the **first** match. Tank's contract and the real scripts agree — no divergence override was needed.

6. **Nits.** `stat` before read (new optional `IFileSystem.fileSizeBytes`, post-parse check kept as defence in depth); `OutputBuffer` trims on a byte-accurate slice respecting UTF-8 continuation bytes; blank `name`/`command` rejected; `package.json` declares `capabilities.untrustedWorkspaces: "limited"`.
