## Key design decisions

Reduced the plan's 5 services to 3 services + 1 pure module. Rejected `ValidationStateService` (the script owns the state file — it is the interop contract) and `ScriptSelectorService` (stateless pure function; `GitHubWorkflowRunnerService` precedent does this inline). Adopted a hybrid execution mechanism: headless `spawn` for `check`/`validate`, but `vscode.window.createTerminal` for `setup` because it is long-running, installs dependencies, and the user must see and trust it.

Identified command injection via `requirements.json` as a genuine RCE vector (`Invoke-Expression $Tool.InstallCommand`, and the shipped data already contains a shell chain operator). Control adopted: the extension **never** executes `install.*` strings — they are display-only.
